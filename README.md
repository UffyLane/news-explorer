## About

News Explorer is a full-stack news search and bookmarking application. Users can search for real-time news articles on any topic, create an account, and save articles to a personal dashboard.

Built with a deliberately non-standard stack — **Python + FastAPI** on the backend instead of Node.js, **PostgreSQL** instead of MongoDB, and **Docker** for containerization. The goal was to demonstrate that full-stack development isn't one-size-fits-all and to expand beyond the typical bootcamp toolset.

## Features

- **News search** — real-time article search via News API
- **Authentication** — secure sign up and log in with JWT
- **Save articles** — bookmark articles to your personal dashboard
- **Delete saved articles** — manage your saved collection
- **Protected routes** — dashboard requires authentication
- **Interactive API docs** — Swagger UI auto-generated by FastAPI
- **Dockerized** — full stack runs in containers locally
- **CI pipeline** — GitHub Actions validates builds on every push
- **Responsive design** — mobile and desktop

## API Endpoints

| Method | Endpoint | Auth | Description |
|--------|----------|------|-------------|
| POST | `/signup` | No | Create account |
| POST | `/login` | No | Log in, receive JWT |
| GET | `/users/me` | Yes | Get current user |
| GET | `/news/search` | No | Search news articles |
| GET | `/articles` | Yes | Get saved articles |
| POST | `/articles` | Yes | Save an article |
| DELETE | `/articles/{id}` | Yes | Delete saved article |

> Full interactive docs available at: https://news-explorer-7bgk.onrender.com/docs

## Running Locally with Docker

```bash
git clone https://github.com/UffyLane/news-explorer.git
cd news-explorer
```

Create `backend/.env`:
```
DATABASE_URL=postgresql://postgres:postgres@db:5432/news_explorer
SECRET_KEY=your_secret_key
```

Create `frontend/.env`:
```
VITE_API_BASE_URL=http://localhost:3001
```

```bash
docker compose up --build
```

| Service | URL |
|---------|-----|
| Frontend | http://localhost:8081 |
| Backend | http://localhost:3001 |
| API Docs | http://localhost:3001/docs |

## CI/CD

GitHub Actions runs on every push to `main`:
- Builds the frontend
- Installs backend dependencies
- Validates backend imports

Pipeline config: `.github/workflows/ci.yml`

- **Backend** → Render (Docker container deployment)
- **Database** → Neon PostgreSQL (serverless cloud PostgreSQL)
